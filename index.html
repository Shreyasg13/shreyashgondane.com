Research focus

  • Claim-level provenance for LLM agents. Turning every number an agent reports into a structured claim that points at the exact value in a stored source snapshot, and verifying it before anything is published.
  • Point-in-time evaluation. Preventing look-ahead leakage: an agent may only see data fetched before its decision time, and its record is scored only on calls made in advance.
  • Tamper-evident records. Append-only, hash-chained ledgers of agent calls, so a track record cannot be edited after the fact.
  • Distilling coding agents. A builder/critic "twin" loop in which cheap models build and a strong model reviews, recording labelled trajectories and corrections for later distillation.

GlassBox

Open source · MIT · Python, FastAPI, Next.js, Postgres

A multi-agent investment-research committee built around verification. Its first milestone (release s3-part1) adds a point-in-time snapshot store for every data fetch, structured claims with exact source pointers, a verification gate that re-checks every number against its source (with snapshot integrity and unit checks), a compliance filter, and an append-only hash-chained ledger.

Twin-agent build lab

Ongoing · agent orchestration, trajectory datasets

An experiment in building real software with a free model as the builder and a strong model as planner and reviewer. Every run is traced; accepted runs, rejected runs and before/after correction pairs form a labelled dataset for studying agent distillation. Includes CPU benchmarks of small local coding models.
